# cyber-journey

My public learning log as I break into cybersecurity.

## Goal
1. **SOC analyst** first: detection, triage, log analysis, incident response
2. **GRC** next: risk, policy, compliance, frameworks
3. **Pentesting** after that: offensive skills built on a defensive foundation

## Repository layout
| Folder | What goes in it |
|---|---|
| `01-notes/` | Study notes (networking, Linux, Windows, Security+) |
| `02-labs/` | Home lab builds and hands-on exercises |
| `03-write-ups/` | Investigations and lab write-ups |
| `04-automation/` | Scripts and workflows I build |

## My safety rules
I never commit:
- Passwords, API keys, tokens or private keys
- Real IP addresses (I use the documentation ranges 192.0.2.0/24, 198.51.100.0/24 and 203.0.113.0/24)
- Screenshots showing personal data (emails, usernames, MAC addresses, hostnames, browser tabs, notifications)
